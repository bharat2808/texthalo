# TextHalo 0.1.15

TextHalo now uses the active app’s normal paste handler for dictation and completed Assistant answers when no text has already been streamed into the editor.

- Paste into editors that do not expose their text or caret through macOS Accessibility, including web editors.
- Wait for the shortcut to release, then send Cmd+V using the current keyboard layout.
- Restore the previous clipboard when enabled, including after clipboard-write or event-dispatch failures, while preserving newer copies.
- Retain the source-app check, cancellation, and refusal of identifiable secure fields.
- Keep snapshot-verified streaming and scoped Undo; clipboard paste does not create an Undo receipt.
- Fix creation of the existing insertion-diagnostic directory.

Apple Silicon only; macOS 14 or later. Live compatibility across every app and browser editor has not been verified. This release does not include the separate localization branch.

Apps distributed before the R2 migration still use the old GitHub update endpoint. Install from texthalo.app to move onto R2 updates.

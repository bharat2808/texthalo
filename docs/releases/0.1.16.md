# TextHalo 0.1.16

- Localized desktop and website interfaces in Canadian French, Latin American Spanish, Brazilian Portuguese, Italian, Japanese, Simplified Chinese, and Traditional Chinese alongside English. Follow the Mac/browser language or save a manual choice; voice and dictation languages stay independent.
- Native Japanese and Mandarin pronunciation for Kokoro, with 5 Japanese and 8 Mandarin voices. Pronunciation support is bundled; existing installations can download missing voice files while reusing their models.
- One additional-language action installs eSpeak language support and missing Kokoro voice files together. Existing eSpeak installations can repair missing weights, with clearer progress and retry states.
- Compact model/download controls and regrouped Home actions make voice and shortcut setup easier to find.

- New website third-party licenses page with dependency versions, original notices, upstream links, and speech-model/dictionary attribution.

Apple Silicon Macs only, macOS 14 or later. On-device Assistant requires supported Apple Intelligence hardware and macOS 26 or later.

Translations use machine-assisted drafts with reviewed core UI terminology. Full native-speaker editorial review remains pending.

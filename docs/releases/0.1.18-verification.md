# TextHalo 0.1.18 release verification

- JavaScript release, relay, localization, and contract suite: 96 passed.
- Rust locked unit/integration suite: passed; model-download and device-specific tests remain ignored by the standard suite.
- Website browser suite: 24 passed. The storage-disabled navigation test now opens the collapsed navigation before choosing Pricing.
- Kindle library and player browser checks: six tests cover live completed chapters, saved playback, chapter selection, preparation without Chrome, and connection status.
- Kindle section visually reviewed at desktop width and Japanese mobile width; localized copy and metadata cover all seven additional languages.

The optional broader desktop browser suite reported 41 passes and 28 failures in existing Assistant/settings/localization expectations. Those screens were not changed in this release preparation, and these failures remain unresolved. This is not a claim that every desktop browser test passes.

The original private updater key was lost when the previous release Mac was erased. The replacement key is stored outside the repo in the login Keychain and the private `.tauri` key file. The 0.1.18 app uses `updates/v2/latest.json`; the legacy `latest.json` feed must remain unchanged. Existing installations require one manual installation of 0.1.18 before receiving future updates.

The automated release receipt in `release-artifacts/0.1.18/release-receipt.json` records the exact source commit and asset checksums after Apple notarization, Gatekeeper checks, archive validation, and updater signature verification.
